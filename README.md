# ASF

ASF is a tower defense game developed in Unity, where the player controls a mobile turret to defend a base against waves of alien enemies.

## Overview

ASF was developed as a course project for **IE2073** during the second semester of Year 2. The project was completed within approximately **one week**.

The game focuses on a simple tower-defense scenario: the player controls a turret, moves around the battlefield, and shoots incoming alien enemies while protecting the base. The game ends when the base's health reaches zero.

## Gameplay

The objective is to defend the base from incoming alien enemies for as long as possible.

### Controls

| Key | Action |
| --- | --- |
| `W` `A` `S` `D` | Move |
| `Space` | Fire |

The player can move around the battlefield and fire at approaching enemies. If the **base health reaches zero**, the game ends.
